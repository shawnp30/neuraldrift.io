# ComfyUI on RTX 5080: Complete Setup Guide

ComfyUI is a node-based interface for running image, video and audio generation locally. This guide covers Windows with an NVIDIA GPU, with RTX 5080 specifics. Install steps follow the [official ComfyUI README](https://github.com/comfyanonymous/ComfyUI#installing); the run times below come from NeuralDrift execution records, each linked to its workflow page.

## Hardware Requirements

The RTX 5080 has 16 GB of VRAM and uses NVIDIA's Blackwell architecture. Blackwell GPUs need a PyTorch build compiled for **CUDA 12.8 or newer**. Builds for CUDA 12.1 or 12.4, which many older ComfyUI guides still recommend, do not include Blackwell kernels and typically fail with `CUDA error: no kernel image is available` or report no usable GPU.

You also need:

- A current NVIDIA driver. The ComfyUI README recommends updating drivers first if the portable build does not start.
- Enough disk space for models. A single SDXL checkpoint is about 7 GB, and FLUX models are larger.

How much VRAM a workflow needs depends on the model, precision, resolution and batch size. Check a workflow against your GPU in the [compatibility matrix](/compatibility) before downloading large models.

## Step 1 — Choose an Install Method

**Windows portable (recommended for most users).** The official portable build ships with its own Python and PyTorch. Per the ComfyUI README it currently bundles Python 3.13 and PyTorch for CUDA 13.0, which supports the RTX 5080. Download it from the [ComfyUI releases page](https://github.com/comfyanonymous/ComfyUI/releases), extract it, and run `run_nvidia_gpu.bat`. See [why the portable build avoids most setup problems](/guides/why-choose-portable).

Use the NVIDIA portable build meant for current GPUs. The README marks the separate build for 10-series and older cards with: do not use it on 20-series and newer GPUs.

**Manual install.** Use this if you want to manage Python yourself. The remaining steps cover it.

## Step 2 — Install Python and Git

The ComfyUI README states Python 3.13 is very well supported, and suggests 3.12 if a custom node's dependencies fail to install on 3.13.

```bash
python --version
git --version
```

You do not need the separate CUDA Toolkit (`nvcc`) to run ComfyUI. PyTorch's CUDA wheels include the runtime libraries they need.

## Step 3 — Clone ComfyUI and Create a Virtual Environment

```bash
git clone https://github.com/comfyanonymous/ComfyUI
cd ComfyUI
python -m venv venv
.\venv\Scripts\activate
```

Activate the virtual environment every time you open a new terminal.

## Step 4 — Install PyTorch for the RTX 5080

This is the step older guides get wrong. Install the CUDA 13.0 build listed in the ComfyUI README:

```bash
pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130
pip install -r requirements.txt
```

Then confirm PyTorch can see the GPU:

```bash
python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

You should see `True` and `NVIDIA GeForce RTX 5080`. If you see `False` or a `no kernel image` error, you have a PyTorch build that predates Blackwell support. Uninstall `torch`, `torchvision` and `torchaudio`, then reinstall with the command above.

> NeuralDrift's recorded RTX 5080 runs used ComfyUI 0.33.0, Python 3.11.9 and PyTorch `2.11.0.dev20260211+cu128` on Windows. Any build for CUDA 12.8 or newer supports the card.

## Step 5 — Enable ComfyUI Manager

ComfyUI Manager installs, updates and manages custom nodes from inside the UI. Current ComfyUI versions include it; per the README, install its dependencies and launch with the flag:

```bash
pip install -r manager_requirements.txt
python main.py --enable-manager
```

For installing nodes manually and fixing node errors, see the [custom nodes guide](/guides/custom-nodes).

## Step 6 — Download a First Model

Place checkpoints in `ComfyUI/models/checkpoints/`.

- **SDXL Base 1.0:** `sd_xl_base_1.0.safetensors` from [stabilityai/stable-diffusion-xl-base-1.0](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0).
- **FLUX.1 Dev:** uses separate diffusion model, text encoder and VAE files in different folders. The [Flux.1 Dev workflow page](/workflows/01) lists each file, its folder and its source.

For where every model type goes, see the [model folder guide](/guides/model-folders).

## Step 7 — Launch ComfyUI

```bash
python main.py
```

Open `http://127.0.0.1:8188` in your browser. With 16 GB of VRAM the default memory management is the place to start. If a workflow runs out of memory, try `--lowvram`, and lower the batch size or resolution.

## RTX 5080 Settings

These are the settings from NeuralDrift's recorded RTX 5080 runs. They are what was measured, not tuned optimums:

| Model | Resolution | Steps | CFG | Sampler / scheduler |
| ----- | ---------- | ----- | --- | ------------------- |
| SDXL (Juggernaut XL v9) | 1024×1024 | 20 | 7 | euler / karras |
| SD 1.5 (v1-5-pruned-emaonly-fp16) | 512×512 | 20 | 7 | dpmpp_2m / karras |
| FLUX.1 Dev FP8 | 512×512 | 20 | 1 | euler / simple |

FLUX.1 Dev is guidance-distilled and is normally run at CFG 1. Higher CFG values intended for SD 1.5 and SDXL do not carry over.

## Your First Workflow

1. ComfyUI opens with a default text-to-image graph. To use a NeuralDrift workflow instead, download its JSON and drag it onto the canvas.
2. In the `Load Checkpoint` node, select the model you downloaded.
3. Enter a prompt and click **Run** (**Queue Prompt** in older versions).
4. If nodes show in red, open ComfyUI Manager and choose **Install Missing Custom Nodes**.

Keep batch size 1 and fewer steps while you test prompts, then raise them for final renders.

## Common Issues

**`no kernel image is available` or `torch.cuda.is_available()` is False on an RTX 5080.** Your PyTorch build predates Blackwell support. Reinstall PyTorch as in Step 4.

**CUDA out of memory.** Lower the batch size to 1, reduce resolution, launch with `--lowvram`, or use a lower-precision model. See [GPU errors and VRAM issues](/guides/gpu-errors).

**Black or blank images.** Often a VAE that does not match the model, or precision problems. Load the VAE the model was released with through a `VAELoader` node.

**Generation runs on the CPU.** Check that the virtual environment is active, so ComfyUI uses the venv's CUDA build of PyTorch rather than a system Python.

**Missing nodes.** Open ComfyUI Manager and click **Install Missing Custom Nodes**, or follow the [custom nodes guide](/guides/custom-nodes).
